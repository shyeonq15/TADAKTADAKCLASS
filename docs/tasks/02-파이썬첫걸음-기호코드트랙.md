## 1. 파이썬 첫걸음 43강 (`lessons.json`)

**형식은 예전과 같습니다.** `LessonRow`(src/data/codeNotes.ts)의 필드를 그대로 쓰므로 화면 코드를 고치지 않아도 43강이 바로 나옵니다.
추가된 것은 `unit` 필드 하나뿐입니다 (예: `"6단원 · 조건 (선택문)"`).

한 강의 흐름은 모두 같습니다:
`생각 열기 → 개념 → 예시 코드와 결과 → 자주 하는 실수 → 한눈에 정리 → 문제로 확인하기 ①②③ → 따라 치기 → 결과 맞히기 → 빈칸 채우기`

할 일:
1. **`npm run build`로 43강이 모두 열리는지 확인** (`generateStaticParams`가 `LESSON_COUNT`를 쓰므로 자동)
2. **강의 목록을 단원별로 묶어 보여 주기** (`LessonList.tsx`): `unit` 값이 바뀌는 곳에 단원 제목을 넣고, 43개가 한눈에 들어오도록 정리. 잠금 규칙(앞 강 통과 시 열림)은 그대로
3. **확인 문제가 있는 슬라이드**: 지금처럼 맞혀야 "다음"으로 넘어가는지, 아니면 그냥 넘어갈 수 있는지 확인하고, 틀려도 넘어갈 수 있게 유지 (점수에는 안 들어감)
4. **진도 데이터 주의**: 강 번호가 바뀌었으므로 `progress.cleared`의 `lesson-n`이 예전 강을 가리킵니다. 시범 운영 전이라면 그대로 두고, 이미 학생 데이터가 있으면 선생님께 물어본 뒤 초기화 여부를 정할 것
5. `codeNotes.ts` 맨 위 주석의 "14강"을 실제 개수로 고치기
6. **따라 치기 코드에 무작위가 있는 강(43강)**: `output`이 예시 값이고 `question`이 "실행 결과로 나올 수 있는 것은?"으로 들어 있음. 결과 맞히기 화면이 `question`을 쓰는지 확인

## 2. 기호·코드 트랙 (`symbol-track.json`, `code-track.json`)

**형식은 `korean-track.json`과 같습니다** (`tiers[] → stages[] → passages[]`). 차이점:

- 단계마다 `title`(예: "elif 여러 갈래")과 `lessons`(연결된 첫걸음 강 번호)가 있음
- 지문에 `lines`(줄 수), 코드 트랙과 기호 마스터·레전드에는 `output`(실제 실행 결과), 입력이 필요한 코드는 `inputs`가 있음
- **타수 규칙**: 영문·기호 1글자 = 1타, Enter = 1타, **줄 앞 들여쓰기는 자동으로 채워지므로 세지 않음**. 기존 타자 엔진의 코드 모드 들여쓰기 자동 채움과 맞는지 확인
- **한 판 분량은 티어마다 `round.passagesPerRound`에 있음** (평균 지문 시간으로 계산해 한 판 ≈ 2분). 한글 트랙처럼 고정 숫자가 아니므로, `game.ts`의 `ROUND_SIZE`를 트랙별로 바꾸거나 JSON의 `round` 값을 읽도록 할 것

| 트랙 | 브론즈 | 실버 | 골드 | 다이아 | 마스터 | 레전드 |
| --- | --- | --- | --- | --- | --- | --- |
| 기호 | 기호 자리 연습 · 5 | 기호 조각 · 19 | 한 줄 식 · 10 | 기호 많은 한 줄 · 10 | 짧은 코드 · 6 | 촘촘한 코드 · 4 |
| 코드 | 한 줄 코드 · 4 | 두세 줄 · 4 | 조건문 · 3 | 반복문 · 5 | 리스트 · 4 | 함수·종합 · 3 |

(숫자 = 한 판에 치는 지문 수)

할 일:
1. 작업 01에서 한글 트랙에 연결한 방식 그대로 `symbol`, `code` 트랙을 새 JSON으로 연결 (기존 `symbol.json`, `code.json`은 대체. 다른 곳에서 쓰면 함께 옮기고 지우기)
2. **코드 지문은 줄바꿈과 들여쓰기 유지**. `inputs`가 있는 지문은 타자 연습에는 영향 없음 (나중에 결과 맞히기에 쓸 수 있게 데이터만 유지)
3. 단계 선택 화면에 `title`을 보여 주고, 가능하면 "이 단계는 첫걸음 ○강과 연결돼요" 안내와 해당 강 링크(`/learn/n`)를 넣기
4. 기존 `code-notes.json`(코드 지문 설명 카드)은 예전 `code.json` 지문 순서에 묶여 있음. 새 코드 트랙에서는 설명 카드 대신 `lessons` 연결로 대신하고, 카드가 꼭 필요하면 선생님께 확인
5. 확인: `npm run lint`, `npm run build` 오류 없음 → 선생님께 확인 방법 안내 (`/learn` 1강과 43강, `/practice/code`와 `/practice/symbol`의 브론즈 1단계·레전드 5단계)
